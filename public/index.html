Paperback Extension Repo

Paperback Extension & Source Repo Compilation — a unified list of the 3rd party extension and source repositories for Paperback 0.8 and 0.9. Tap Add to Paperback on any repo below to open its install page.

Install Paperback, tap Add to Paperback on a repo, then tap Add to Paperback again on the page that opens.

Paperback runs on iOS and iPadOS. On other devices you can still open each repo's install page or its GitHub page from the list below.

0.9 sources don't work on 0.8. If you got Paperback from the App Store you're on 0.8. You can install 0.8 extensions in the 0.9 client, but not the other way around.

All credit goes to the developers of these extensions. Please leave any issues on the developer's own repo or on the extension Discord. Missing a repo? Open a pull request — this page is generated from the README.
