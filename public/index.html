Paperback Extension Repo

Find community-maintained extension repositories and sources for Paperback 0.8 & 0.9 in one cosy directory. Browse included sources, compare repositories, and open any repo's installation link in a tap.

0.9 REPOS 0.8 REPOS

🌷 Install Paperback, tap Add to Paperback on a repo, then tap the same button again on the page that opens.

🌷 Paperback runs on iOS and iPadOS. On other devices you can still open each repo's install page or its GitHub page below.

💡 0.9 sources don't work on 0.8. If you got Paperback from the App Store you're on 0.8. You can install 0.8 extensions in the 0.9 client, but not the other way around.

🎟️ How do I get Paperback 0.9?

0.9 is invite-only through TestFlight for now. To request an invite:

  1. Join the official Paperback Discord.
  2. Become an active Patreon supporter or a Discord server booster.
  3. Link your Discord account in your Patreon app settings.
  4. Hit Request TestFlight invitation in the 📨・testflight channel.

Your email stays private. Rather watch someone do it? Here's a video walkthrough of the whole TestFlight request. Not fussed about any of that? A public App Store release for 0.9 is planned, so you can simply wait. 🌷

💡 Extension Recommendations?

Extension recommendations are highly subjective, so there is rarely one perfect answer. For broader directories and different approaches to comparing websites, try EverythingMoe or Wotaku's website list.

📝 Extension Request?

Submit requests with the /request-extension slash command in the Inkdex Discord.

The form asks for the website's complete HTTPS URL and a short reason explaining why it would make a useful extension.

⚠️ Worth knowing

therobbiedavis/paperback-extension-repo still turns up in searches, but it's built for Paperback 0.6 and won't install on 0.8 or 0.9 — skip it.
