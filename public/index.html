Paperback Extension Repo

Paperback Extension & Source Repo Compilation — every 3rd party extension repo for Paperback 0.8 & 0.9, in one cosy little list. Tap Add to Paperback on any repo, or peek inside to see the sources it ships.

🌷 Install Paperback, tap Add to Paperback on a repo, then tap Add to Paperback again on the page that opens.

🌷 Paperback runs on iOS and iPadOS. On other devices you can still open each repo's install page or its GitHub page below.

💡 0.9 sources don't work on 0.8. If you got Paperback from the App Store you're on 0.8. You can install 0.8 extensions in the 0.9 client, but not the other way around.

Want 0.9? There are three ways in right now — donate to the Paperback Patreon, boost the Paperback Discord server, or wait for the public App Store release, which is planned.
