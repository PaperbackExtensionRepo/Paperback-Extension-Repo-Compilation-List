About this directory

How this Paperback repository directory is put together: which repos get listed, where each source list comes from, how often the site rebuilds, and who maintains it.

← Back to all repositories

What this site is

Paperback Extension Repo is an independent, community-run index of extension repositories for the Paperback reading app. It exists because these repositories are scattered across GitHub, Discord messages and forum posts, and there was no single place to see what exists and which Paperback version each one targets.

The site hosts nothing itself. Every repository listed here belongs to the developer who built it, and installing one sends you straight to their own URL.

How a repository gets listed

A repository is added when it meets all of these:

  • It is a genuine Paperback extension repository — it publishes a versioning.json manifest that the app can install from.
  • It targets Paperback 0.8 or 0.9. Repositories built for 0.6 and earlier are not listed as installable; the one that still shows up in search results is documented separately so people stop trying it.
  • It is publicly reachable, without a login or paywall.
  • Its developer publishes it for others to use.

There is no ranking, no sponsorship and no paid placement. Ordering within each version section is simply the order repositories were added. Nobody pays to appear here and nothing is accepted in exchange for a listing.

Where the source lists come from

The repository table lives in the project's README on GitHub, which is the single source of truth for what is listed. Everything else is generated from it.

The list of sources shown under each repository is not typed by hand. On every build the site fetches each repository's own versioning.json and reads the sources, versions and content ratings straight out of it. That means a source list here can never be more than a day out of date with the repository it describes, and if a developer adds or removes a source it appears here on the next build without anyone editing this site.

When a repository is unreachable at build time, its card says "Source list unavailable" rather than showing a stale list from an earlier build.

How often it updates

The site rebuilds automatically once a day, and again whenever the repository list changes. Both the repository list and every source list are regenerated on each build.

Last rebuilt 26 August 2026.

Corrections and additions

If a repository is missing, listed under the wrong version, or has moved, please open an issue or send a pull request — editing one row of the README is enough. Repository developers who would rather not be listed can ask and it will be removed.

For help with an extension itself, contact its developer rather than this site: their GitHub link is on every card, and the Paperback Discord has an #other-repos channel for repositories that aren't Inkdex's.

Independence

This site is not affiliated with Paperback, with Inkdex, or with any of the repositories it lists. All names, trademarks and logos belong to their respective owners. It carries no advertising, no tracking scripts and no analytics — nothing you do here is recorded or sent anywhere.
